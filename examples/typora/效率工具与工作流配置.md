# 效率工具与工作流配置

> 一套好的工具链能让写作效率提升数倍。本文分享我在日常写作中使用的工作流，涵盖编辑器配置、版本管理和自动化处理。

## 一、编辑器选择

### 1.1 Typora + Obsidian 双剑合璧

| 场景 | 工具 | 优势 |
|------|------|------|
| 日常写作 | [Typora](./Typora.md) | 所见即所得，沉浸感强 |
| 知识管理 | [Obsidian](./Obsidian.md) | 双向链接，图谱分析 |
| 快速笔记 | [Apple Notes](./Apple Notes.md) | 全局搜索，跨设备同步 |
| 协同编辑 | [Notion](./Notion.md) | 实时协作，数据库视图 |

## 二、版本管理策略

### 2.1 Git 工作流

```bash
# 初始化笔记仓库
cd ~/Documents/notes
git init

# 日常提交
git add .
git commit -m "update: 新增效率工具笔记"
git push
```

### 2.2 分支策略

- `main` — 已发布的笔记
- `draft` — 写作中的草稿
- `review` — 待校对

## 三、自动化转换

### 3.1 Obsidian → Typora 链接转换

当需要将 Obsidian 笔记在 Typora 中打开时，使用本项目的工具一键转换：

```bash
# 整库复制并转换（不修改原始库）
python3 obsidian-to-typora.py ~/obsidian-vault ~/Desktop/for-typora

# 单个文件快速转换
python3 obsidian-to-typora.py 笔记.md 转换后.md
```

转换规则：

| Obsidian 语法 | 标准 Markdown | 说明 |
|------|------|------|
| `[链接](./链接.md)` | `[链接](./链接.md)` | 普通链接 |
| `[显示](./目标.md)` | `[显示](./目标.md)` | 别名链接 |
| `[笔记 → 标题](./笔记.md)` | `[笔记 → 标题](./笔记.md)` | 章节引用 |
| `![](./图片.png)` | `![](./图片.png)` | 嵌入图片 |

### 3.2 Typora → Obsidian

由于 Obsidian 原生支持标准 Markdown 链接，**无需反向转换**。只需将文件移回 Obsidian 库即可。

## 四、主题定制

### 4.1 字体方案

Typora Evergreen 针对中英文混排做了优化：

| 场景 | 字体 |
|------|------|
| 英文正文 | Avenir Next |
| 中文正文 | PingFang SC |
| 中文标题 | Heiti SC |
| 代码 | SF Mono → Cascadia |

### 4.2 颜色系统

- **主色**：`#1a7a6a`（深绿，平静专注）
- **点缀**：`#f2c94c`（金色，突出重点）
- **背景**：浅色/深色双模式，跟随系统
